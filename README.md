# 爽快ゾンビ無双

最初から最強・絶対に死なない。押しよせるゾンビの大群を、剣と銃と必殺技でなぎ倒す3Dアクション!

**遊ぶ: https://roguepink.github.io/sokai/**

## 遊び方

- 「あそぶ」を押すと始まります。主人公は **やられません**。好きなだけ倒して、点数をのばしてください
- スマホは **横向き** がおすすめです(縦でも遊べます)
- やめたいときは 右上の「Ⅱ」→「おわる」。けっかが出て、最高記録が残ります

### スマホの操作

| すること | やりかた |
|---|---|
| 歩く | 画面の **左半分** を指でさわって、そのまま動かす(さわった所がスティックになる) |
| 撃つ | 右下の **「撃つ」を押している間**、ずっと撃つ(近くの敵は 自動で 剣で斬る) |
| 回転斬り | **「回転斬り」** を押す。まわりの敵をまとめて倒す(まわりの輪がたまると また使える) |
| 武器をかえる | 右上の **武器の絵** をさわる。または「◀」「▶」 |
| 一時停止 | 右上の「Ⅱ」 |

歩きながら撃つときは、**左手の親指で歩き、右手の親指で「撃つ」** を押したままにします。

### パソコンの操作

| すること | キー |
|---|---|
| 歩く | W A S D または 矢印キー |
| 撃つ | スペース(押している間)/ 画面をクリックしている間 |
| 回転斬り | Shift または E |
| 武器をかえる | Q / R / マウスのホイール / 数字キー 1〜0 |
| 一時停止 | Esc または P |

### 画面の見かた

- **上のまんなか**: 点数。下の細い棒は「ベストまで あとどれくらいか」
- **左上**: 地図(赤い点 = ゾンビ、赤い丸 = ボス)、倒した数、時間。場所が変わると 場所の名前が少し出ます
- **右上**: 武器の列と、コンボ(続けて倒した数)。コンボが続くほど 点数が何倍にもなります
- **ボス** が出ると 体力の棒が出ます。画面の外にいるときは 矢印で場所を教えます

### うまく動かないとき

- 動きが重いときは ⚙ 設定 →「画質」を **低** に
- 音が出ないときは、⚙ 設定 →「音」が オン か確かめて、画面を一度さわってください(スマホは 画面にさわるまで 音が出ない決まりです)

## LINE で送る・ホーム画面に入れる

- 上のアドレスを LINE に貼れば、タイトルと絵つきの紹介が出る。タップするとすぐ遊べる
- **LINE の中で開いたときは、ホーム画面に入れられない。**メニューから「Safari で開く」(iPhone)/「他のアプリで開く」→ Chrome(Android)を選んでから入れる
  - iPhone(Safari): 共有ボタン →「ホーム画面に追加」 / Android(Chrome): メニュー(︙)→「アプリをインストール」
- 入れたあとは全画面で起動。**一度開けば 電波がなくても遊べる**

## 直して公開するとき

- `main` に push すれば公開される(GitHub Pages)。電波のある人は、**次に開いたとき**に新しい版になる(`sw.js` は まずネットで最新を取りにいく)
- `js/` にファイルを足したり消したりしたら、`sw.js` の `FILES` に書いて `VERSION` を 1つ上げる(書き忘れても、一度開いた人の分は自動で覚える)
- 確認の道具(Mac の画面はつけない・音も出ない):
  - `python3 tools/playtest.py --secs 20 --shots 3` … 自動で遊ばせて写真
  - `python3 tools/playtest_mobile.py --scene heavy|touch|screens|loop|keys|audio|hitch [--cpu 4] [--q mid] [--size 667x375]` … スマホのふり(指の操作・おそいスマホ・画面の流れ・もれ・PC のキー・音の状態・固まり)
  - `python3 tools/playtest_mobile.py --scene offline --hash sw` … 電波なしで起動できるか
