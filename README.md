# 爽快ゾンビ無双

最初から最強・絶対に死なない。押しよせるゾンビの大群を、剣と銃と必殺技でなぎ倒す3Dアクション!

**遊ぶ: https://roguepink.github.io/sokai/**

## 遊び方

- 「あそぶ」を押すと始まります。主人公は **やられません**。好きなだけ倒して、点数をのばしてください
- スマホは **横向き** がおすすめです(縦でも遊べます)
- やめたいときは 右上の「Ⅱ」→「おわる」。けっかが出て、最高記録が残ります

### スマホの操作

| すること | やりかた |
|---|---|
| 歩く | 画面の **左半分** を指でさわって、そのまま動かす(さわった所がスティックになる) |
| 撃つ | 右下の **「撃つ」を押している間**、ずっと撃つ(近くの敵は 自動で 剣で斬る) |
| 回転斬り | **「回転斬り」** を押す。まわりの敵をまとめて倒す(まわりの輪がたまると また使える) |
| ダッシュ | むらさきの **「ダッシュ」** を押す。前へ すばやく体当たりして、ぶつかったゾンビを ふっとばす |
| ジャンプ叩きつけ | 「ダッシュ」を **すばやく 2 回** 押す。高く跳んで 地面に たたきつけ、まわりを まとめて ふっとばす |
| 武器をかえる | 右上の **武器の絵** をさわる(列は 指で横に送れる)。または「◀」「▶」 |
| 武器を ぜんぶ見る | 武器の列の いちばん左 **「▦ 全部」**。31 種類が ならぶので、さわった武器に すぐ かわる |
| 視点をかえる | 右上の **👁(視点)** を短く押す。見下ろし → 肩越し → 一人称 → 見下ろし の順に かわる |
| 視点の設定 | 👁 を **長押し**。向きを変える速さ・自動でゾンビの方を向く・上下の向き をえらべる |
| 向きをかえる | 肩越し・一人称のとき、画面の **右側を なぞる**(「撃つ」を押したまま 指をすべらせても かわる)。さわらないと 自動で ゾンビの方を向く |
| 一時停止 | 右上の「Ⅱ」 |

歩きながら撃つときは、**左手の親指で歩き、右手の親指で「撃つ」** を押したままにします。

### パソコンの操作

| すること | キー |
|---|---|
| 歩く | W A S D または 矢印キー |
| 撃つ | スペース(押している間)/ 画面をクリックしている間 |
| 回転斬り | Shift または E |
| ダッシュ / ジャンプ叩きつけ | F または C(すばやく 2 回で 叩きつけ)/ G で すぐ叩きつけ |
| 武器をかえる | Q / R / マウスのホイール / 数字キー 1〜0(同じ数字を もう一度押すと 11〜、もう一度で 21〜) |
| 武器を ぜんぶ見る | T |
| 視点をかえる / 視点の設定 | V / B |
| 向きをかえる(肩越し・一人称) | 画面をクリックすると マウスで 向きが変わる(Esc で もどる) |
| 一時停止 | Esc または P |

### 画面の見かた

- **上のまんなか**: 点数。下の細い棒は「ベストまで あとどれくらいか」
- **左上**: 地図(赤い点 = ゾンビ、赤い丸 = ボス)、倒した数、時間。場所が変わると 場所の名前が少し出ます
- **右上**: 武器の列と、コンボ(続けて倒した数)。コンボが続くほど 点数が何倍にもなります
- **下のまんなか**: 無双ゲージ(いっぱいで 無双モード)
- **左上の地図の下**: 時間限定チャレンジの札(出ているときだけ)
- **ボス** が出ると 体力の棒が出ます。画面の外にいるときは 矢印で場所を教えます

### 視点(見かた)は 3 つ

- **見下ろし**(🗺️ いつもの): 上から 町を見下ろす。まわりが よく見えて いちばん かんたん
- **肩越し**(🎥): 主人公の うしろから。大群が 目の前に せまってくる 迫力
- **一人称**(👀): 主人公の目で見る。手元に 武器が見える。真ん中の「照準」の方へ 撃つ
- えらんだ視点は 次に遊ぶときも そのまま。タイトルの見本プレイは いつも見下ろし

### 爽快になる しかけ

- **無双モード**: 倒すほど 下の「無双」ゲージが たまる。いっぱいになると 十数秒のあいだ 点数が 2 倍以上(2 回目からは もっと倍)、武器も強くなり、画面のふちが 金色に光る
- **出来事**: ときどき 物資の箱が落ちてくる(開けると 無双モード・点数 3 倍・超・大爆発・空爆・最強武器 などが当たる)/ 金色ゾンビ(倒すと 大きな点数)/ ゾンビの大行進・空から降ってくる・ボスが続けて出る 、など
- **時間限定チャレンジ**: 左上に「〇秒で △体 倒せ!」の札が出る。時間内に できると ボーナス
- **31 種類の武器**: 銃・ミニガン・ロケット・火炎放射器 から、チェーンソー・雷神ハンマー・空爆要請・衛星レーザー・竜巻・隕石召喚・攻撃ドローン まで。最初から 全部 使える
- **こわせる物**: 車・ドラム缶・ガスタンク・ガラス・木の箱・消火栓 など。撃つと こわれ、車やタンクは **大爆発** して まわりのゾンビも ふっとぶ
- **昼と夜・天気**: 7 分で 1 日がめぐる(夕方 → 夜 → 夜明け → 昼)。雨・雷雨・霧・雪・灰 に変わり、雷が ゾンビに落ちることも。夜は 街灯や窓の明かりが ともる
- **広いマップ**: 町・森・川と橋・港・遊園地・空港・軍の基地・墓地・農場 など。新しい場所に行くと 名前が出る

### うまく動かないとき

- 動きが重いときは ⚙ 設定 →「画質」を **低** に。肩越し・一人称は 遠くまで見えるぶん 重いので、重いときは 見下ろしに
- 音が出ないときは、⚙ 設定 →「音」が オン か確かめて、画面を一度さわってください(スマホは 画面にさわるまで 音が出ない決まりです)

## LINE で送る・ホーム画面に入れる

- 上のアドレスを LINE に貼れば、タイトルと絵つきの紹介が出る。タップするとすぐ遊べる
- **LINE の中で開いたときは、ホーム画面に入れられない。**メニューから「Safari で開く」(iPhone)/「他のアプリで開く」→ Chrome(Android)を選んでから入れる
  - iPhone(Safari): 共有ボタン →「ホーム画面に追加」 / Android(Chrome): メニュー(︙)→「アプリをインストール」
- 入れたあとは全画面で起動。**一度開けば 電波がなくても遊べる**

## 直して公開するとき

- `main` に push すれば公開される(GitHub Pages)。電波のある人は、**次に開いたとき**に新しい版になる(`sw.js` は まずネットで最新を取りにいく)
- `js/` にファイルを足したり消したりしたら、`sw.js` の `FILES` に書いて `VERSION` を 1つ上げる(書き忘れても、一度開いた人の分は自動で覚える)
- 確認の道具(Mac の画面はつけない・音も出ない):
  - `python3 tools/playtest.py --secs 20 --shots 3` … 自動で遊ばせて写真
  - `python3 tools/playtest_mobile.py --scene heavy|touch|screens|loop|keys|audio|hitch [--cpu 4] [--q mid] [--size 667x375]` … スマホのふり(指の操作・おそいスマホ・画面の流れ・もれ・PC のキー・音の状態・固まり)
  - `python3 tools/playtest_mobile.py --scene offline --hash sw` … 電波なしで起動できるか
